## Google Sheets / Apps Script
1. Create a new Google spreadsheet.
2. Extensions → Apps Script. Replace the starter code with Code.gs. Save.
3. Reload your spreadsheet. Open BotStore → Set up.
4. Review Google permission request and authorize only your own copied script.
5. Enter your records under the header. Summary recalculates automatically.
ҚАЗ: Жаңа Google кесте → Кеңейтімдер → Apps Script → Code.gs кодын салыңыз. Сақтап, кестені жаңартыңыз. BotStore мәзірінен іске қосыңыз.
РУС: Новая таблица → Расширения → Apps Script → вставьте Code.gs. Сохраните, обновите таблицу, запустите настройку через меню BotStore.
