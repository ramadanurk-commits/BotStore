# Архив исходной Git-истории

`BotStore-v7.bundle` содержит всю прежнюю историю ветки `main` на момент экспорта исходников v7. Исходные авторы, сообщения, даты и SHA сохранены. Последний исходный коммит: `6b69d3c30fedd1b4922cbf85508ebd7667af1538`.

Импорт на GitHub выполнен через API и имеет свою историю коммитов. Bundle позволяет отдельно открыть прежнюю историю без изменения текущего репозитория.

Из корня клонированного проекта выполните:

```powershell
git bundle verify history/BotStore-v7.bundle
git clone history/BotStore-v7.bundle ../BotStore-original-history
git -C ../BotStore-original-history log --oneline
```

Архив предназначен для проверки реального процесса разработки. Коммиты Codex не являются индивидуальными коммитами участников команды. Не меняйте авторов или даты ради требований задания.

В архив не входят локальные зависимости, файлы с секретами, производственная база данных или файлы покупателей.
