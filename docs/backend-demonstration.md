# РК1: тірі сайтта бэкендті көрсету

Негізгі сілтеме: https://botstore-kz-market.ra1k0n.chatgpt.site

Тексеру API: https://botstore-kz-market.ra1k0n.chatgpt.site/api/health

## Демоға дейін

1. Проекторда сайтты ашыңыз. Екі терезе дайындаңыз: ашық клиент терезесі және алдын ала кірген админ терезесі.
2. Админ терезесінде «Қызметке өтінімдер / Заявки на услуги» бөлімін ашыңыз. Админ құқығы сервердегі `ADMIN_EMAIL` арқылы анықталады. Кіруді көрсетілім басталғанша аяқтаңыз.
   Осы бөлімнің жоғарғы жағындағы дерекқор индикаторын тексеріңіз. Ол нақты `/api/health` сұрауының нәтижесін көрсетеді. «Қайта тексеру» батырмасы қосылымды қайта сұрайды.
3. Клиент терезесінде каталогтан өнімді ашып, орнатуға көмек сұрау формасын дайындаңыз. Тест атауы: `[TEST] РК1 демо`. Тест email: `rk1-demo@example.test`. Бұл нақты байланыс адресі емес.
4. Мәтін: «[TEST] Бұл өтінім сабақтағы дерекқор демонстрациясы үшін. Бізге СТО ботының орнату тәртібін түсіндіру қажет». Деректерді өңдеуге келісімді белгілеңіз.
5. Карта нөмірін, нақты төлемді немесе клиенттердің жеке мәліметтерін көрсетпеңіз. Тест өтінім нақты сатылым болып есептелмейді.

## 70 секундтық көрсетілім

| Уақыт | Әрекет | Не дәлелдейді |
| --- | --- | --- |
| 0-15 сек | Өнімді және өтінім формасын көрсетіңіз | Жұмыс істейтін интерфейс |
| 15-30 сек | Өтінімді жіберіп, шыққан ID-ні көрсетіңіз | Сервер форманы қабылдады |
| 30-50 сек | Админнің іздеу өрісіне өтінім ID-сін қойып, «Іздеу» басыңыз | Сервер D1-дегі сол жазбаны іздеп оқыды |
| 50-60 сек | Админ бетін қайта жүктеп, сол өтінім сақталғанын көрсетіңіз | Дерек браузер жадына ғана тәуелді емес |
| 60-70 сек | `/api/health` ашыңыз | Жұмыс істейтін API және D1 қосылымы |

Қызметке өтінім батырмасы қазақша «Өтінім қалдыру / Қызметке өтінім», орысша «Оставить заявку / Заявка на услугу» болып көрінуі мүмкін. Нақты мәтінді қорғауға дейін сайттың таңдаған тілінен тексеріңіз.

Іздеу нәтиже бермесе, статус сүзгісін «Барлығы / Все» күйіне қайтарыңыз. ID-ді толығымен немесе алғашқы сегіз таңбасын енгізуге болады. Бетті қайта жүктегенде іздеу өрісі тазаланады: сол ID-ді қайта енгізіп, жазбаның сақталғанын көрсетіңіз. «Нөмірін көшіру» батырмасы толық ID-ді көшіреді.

Кодтан іздеуді түсіндіру: `app/service-requests.tsx` `URLSearchParams` арқылы `q` мен `status` жібереді. `lib/sales-api.ts` админ құқығын тексеріп, параметрленген `LIKE` сұрауын орындайды. Іздеу бүкіл кестеге қолданылады, сондықтан соңғы 200 жазбаға кірмеген ескі өтінімді де табады. SQLite-тің `LIKE` регистрге тәуелсіз салыстыруы ASCII әріптеріне қолданылады; қазақша/орысша атауларда жазылған регистрді пайдаланыңыз немесе ID/контакт арқылы іздеңіз.

Тест жазбасын админде `declined` / «Бас тартылды» күйіне ауыстырып, ішкі ескертпеде сабақ демонстрациясы екенін белгілеуге болады. Оны нақты клиент сұранысы ретінде ұсынбаңыз.

## Неге бұл бэкенд

`app/sales.tsx` браузерден JSON жібереді. `app/api/[...path]/route.ts` сұрауды `lib/api.ts` өңдегішіне береді. `lib/sales-api.ts` аты, байланысы, келісімі, мәтіні мен origin-ді тексереді. Сәтті сұрауды параметрленген `INSERT OR IGNORE` арқылы `service_requests` кестесіне жазады. Админнің GET сұрауы `SELECT` арқылы сол жазбаны қайта оқиды.

Қосылымды `lib/db.ts` ішіндегі `db()` функциясы D1 binding `DB` арқылы алады. Өндірістік БД Cloudflare-де орналасқан. Сайт кодын қайта жариялау не ноутбукті өшіру дерекқор жазбаларын жоймайды. Жергілікті тестілік БД өндірістік БД-дан бөлек.

`GET /api/health` нақты БД сұрауын орындайды. Ол бос JSON немесе клиентте жасалған уақытты қайтармайды. БД жоқ болса HTTP 503, жұмыс істесе HTTP 200 қайтарады. Құпия ақпарат пен клиент жазбаларын қайтармайды.

## Қысқа командалық тексеріс

```powershell
node scripts/production-smoke.mjs
```

Бұл тексеріс анонимді HTTPS сұрауларын қолданады. Хостинг автоматтандырылған сұрауды HTTP 403 / 1010 арқылы бұғаттаса, тестті «өтті» деп белгілемеңіз. Тірі браузер демосын қолмен орындаңыз. Sites сервис токені тек сол сайтқа арналған серверлік тексеруге беріледі, ол админнің жеке авторизациясын алмастырмайды және кодқа қосылмайды.

## Демода ақау шықса

- Кіру беті ашылса, алдын ала кірген админ терезесіне өтіңіз.
- Каталог немесе форма қате берсе, интернетті және `/api/health` тексеріңіз.
- HTTP 503 болса, жұмыс істемейтін бэкендті жұмыс істейді деп көрсетпеңіз. Бұл қосылым ақауы, браузерден жалған дерек көрсету шешім емес.
- Форма сақталды, бірақ админде көрінбесе, тізімді жаңартып, өзіңіздің админ аккаунтыңызбен кіргеніңізді тексеріңіз.
- Нақты сатып алу мен ақша аударуды қорғауда орындау қажет емес. Өтінімнің жазылып, қайта оқылуы талаптағы серверлік әрекетті дәлелдейді.
