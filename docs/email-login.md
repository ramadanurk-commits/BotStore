# Вход по email и паролю

Сайт: https://botstore-kz-market.ra1k0n.chatgpt.site

## Покупатель

1. Откройте «Мои покупки / Жеке кабинет».
2. Выберите регистрацию, введите имя, email и пароль от 15 до 128 символов.
3. Подтвердите согласие на создание аккаунта.
4. Сохраните показанный код восстановления в менеджере паролей. Он показывается один раз и даёт доступ к аккаунту; никому его не передавайте.
5. В дальнейшем входите по email и паролю.

Email используется как логин: подтверждение владения почтовым ящиком и отправка писем не подключены. Восстановление работает по сохранённому коду. При восстановлении пароль и код заменяются, прежние сессии прекращают действовать. Без пароля и кода восстановить отдельный почтовый аккаунт автоматически нельзя.

## Уже есть аккаунт через ChatGPT, включая владельца

1. Войдите в существующий аккаунт через ChatGPT.
2. Откройте личный кабинет или админку и разверните «Подключить вход по email».
3. Установите новый пароль и сохраните код восстановления.
4. Выйдите из аккаунта. После этого можно войти через подключённый email и пароль.

Привязка использует подтверждённую платформой личность и её email. ID пользователя остаётся прежним, поэтому сохраняются покупки, товары и права. Админские права почтовому входу выдаются только при привязке из существующего админского аккаунта. Регистрация с совпадающим email не даёт админские права и не объединяет чужие аккаунты.

Новые почтовые аккаунты и аккаунты ChatGPT с таким же адресом не объединяются автоматически. Если вы уже пользовались ChatGPT-входом, используйте привязку из своего кабинета.

## Реализация и проверка

- `lib/email-auth.ts`: регистрация, вход, выход, привязка и восстановление.
- `app/email-auth.tsx`: формы на трёх языках.
- `drizzle/0004_email_auth.sql`: отдельные таблицы учётных данных и сессий; прежние таблицы и записи сохраняются.
- Пароли хранятся как scrypt-хеш с индивидуальной солью: N=32768, r=8, p=3. Открытых паролей в базе нет.
- Сессии: случайный 256-битный токен в host-only HttpOnly/Secure/SameSite cookie, в базе хранится SHA-256 хеш токена. Срок — 7 дней, до 10 активных сессий на аккаунт.
- Код восстановления: случайные 256 бит; в базе только его хеш. Смена пароля увеличивает версию учётных данных и отзывает старые сессии.
- POST-запросы требуют совпадения Origin. Попытки входа и восстановления ограничены по email и IP. Данные авторизации не помещаются в localStorage.
- Владелец привязывает почту из действующей сессии ChatGPT; запрос клиента не может назначить роль или чужой user ID.

```bash
npm run test:auth
npm run test:api
npm run test:backend
npm run typecheck
```

Источники для параметров и cookie: https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html ; https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html ; https://developers.cloudflare.com/workers/runtime-apis/nodejs/crypto/ .

Google, Apple и Telegram как самостоятельные провайдеры входа не подключены. Их кнопки не показываются как работающие способы входа.
