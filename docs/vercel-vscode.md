# BotStore: VS Code және Vercel

Код: https://github.com/ramadanurk-commits/BotStore .
Жұмыс істеп тұрған сайт: https://botstore-kz-market.ra1k0n.chatgpt.site .
Vercel URL-і нақты жариялау сәтті аяқталғаннан кейін ғана қосылады.

## 1. Кодты VS Code-та ашу

Компьютерде Node.js 24 LTS, Git және VS Code болуы керек.
Node.js: https://nodejs.org/en/download . Орнатқан соң VS Code-ты толық жауып,
қайта ашыңыз. `node --version` командасы нұсқаны көрсетуі керек.
`node не распознано` қатесі болса, Node.js орнатылмаған немесе терминал
орнатудан бұрын ашылған.

Жобаны алғаш жүктеу үшін PowerShell-де:

```powershell
git clone https://github.com/ramadanurk-commits/BotStore.git
cd BotStore
code BotStore.code-workspace
```

Осы репозиторийді бұрын clone жасаған болсаңыз, Source Control-та өз жұмысыңызды
сақтап, сол папкада `git pull --ff-only` орындаңыз. Өзгерістер болса, оларды
жоймаңыз. Бұрын ZIP ашқан папка Git репозиторийі болмауы мүмкін: жаңа clone-ды
басқа папкаға жүктеп, ескі көшірмені сақтаңыз.

Git жоқ болса: репозиторийдегі **Code → Download ZIP**, архивті ашып,
VS Code → **File → Open Folder** арқылы `package.json` тұрған папканы таңдаңыз.
`code` командасы табылмаса да File → Open Folder жұмыс істейді.

VS Code → **Terminal → New Terminal**:

```powershell
node scripts/desktop-start.mjs
```

Алғашқы іске қосу тәуелділіктерді орнатады, бес миграцияны қолданады және
тоғыз дайын өнім қосады. Браузерде http://127.0.0.1:5173 ашыңыз.
Тоқтату: Ctrl+C. Балама: **Terminal → Run Task → BotStore: start locally**.

Бұл — жеке жергілікті база. Өндірістегі клиенттер, тапсырыстар және құпиялар
компьютерге көшірілмейді. Localhost-тағы тестілік админ тек әзірлеуге арналған.
Windows-та іске қосуды өз компьютеріңізде тексеріңіз; осы ортада Windows QA
орындалған жоқ.

## 2. Қорғауда қай кодты көрсету керек

| Көрсетілетін бөлік | Файл | Түсіндіру |
| --- | --- | --- |
| Негізгі бет, каталог, тапсырыс, админ | `app/store.tsx` | Батырма API-ге сұрау жібереді, жауаптан интерфейс жаңарады |
| API нүктелерін қосу | `app/api/[...path]/route.ts` | GET/POST сұраулары сервер өңдеушісіне беріледі |
| Сервердегі бизнес логика | `lib/api.ts` | Өнім, баға, рұқсат және тапсырыс мәртебесі серверде тексеріледі |
| Дерекқор кестелері | `db/schema.ts`, `drizzle/` | SQLite/D1 кестелері және бес кезеңдегі миграциялар |
| Өтінім формасын сақтау/іздеу | `app/sales.tsx`, `lib/sales-api.ts` | Форма → сервер тексеруі → D1 → қайта оқу |
| Email арқылы кіру | `app/email-auth.tsx`, `lib/email-auth.ts` | scrypt хеші, HttpOnly cookie, сервердегі сессия |
| Kaspi Gold аударымы | `app/kaspi.tsx`, `lib/api.ts` | Деректерді көшіру → түбіртек → әкімші тексеруі → файл |
| Үш тіл | `lib/i18n.ts`, `lib/auth-i18n.ts` | kk/ru/en мәтіндері мен тіл ауыстыру |
| Тауарларды салыстыру | `lib/comparison.ts`, `hooks/use-comparison.ts` | Ең көбі үш өнім, браузерде сақтау |
| Vercel конфигурациясы | `vercel.json`, `next.config.ts` | Next.js build және сервер модулін таңдау |
| Vercel-ден API-ге байланыс | `lib/vercel-api.ts`, `lib/vercel-proxy.ts` | Қорғалған серверлік сұрау, cookie және CSRF тексеруі |

Ctrl+P арқылы файл атын теріңіз. Мысалы, `lib/api.ts` ішінен Ctrl+F арқылы
`path[0]==='orders'` немесе `path[1]==='order'` іздеңіз. Біріншісі тапсырыс
жасайды, екіншісі әкімшінің төлем растауын өңдейді.

Айтуға болатын қысқа түсіндірме:

> BotStore шағын бизнеске дайын автоматтандыру құралдарын ұсынады.
> Интерфейс серверге сұрау жібереді. Сервер пайдаланушының рұқсатын тексеріп,
> деректерді D1 базасына сақтайды. Ақылы файл тек төлем расталғаннан кейін
> ашылады. Код GitHub-та сақталған, жергілікті көшірмесін VS Code-та көрсетеміз.

Жеке үлес пен коммиттерді шынайы көрсетіңіз: Codex дайындаған кодты өзіңіз
оқып, түсіндіріп, өзгерте алуыңыз керек.

## 3. Vercel архитектурасы

| Бөлік | Қайда орындалады |
| --- | --- |
| HTML, CSS, React, Next.js | Vercel |
| `/api/*` үшін серверлік gateway | Vercel Node.js Function |
| Бизнес логика, кіру және тапсырыстар | Қазіргі Cloudflare Worker / Sites |
| Тұрақты SQL деректер | Қазіргі Cloudflare D1 |
| Жүктелген жабық ZIP файлдар | Қазіргі Cloudflare R2 |

Бұл көшу базаны басқа провайдерге көшірмейді. Қазіргі Worker мен оның D1/R2
ресурстары жұмысын жалғастыруы керек. Тапсырыстар мен аккаунттар бір базада
сақталады. Қорғауда бэкенд пен база Cloudflare-де екенін ашық айтыңыз.

Vercel кіріс сұрауындағы `oai-authenticated-user-*` тақырыптарына сенбейді.
Gateway оларды алып тастап, тек BotStore сессия cookie-сін жібереді. Сондықтан
сырттан жалған тақырып беру арқылы админ болу мүмкін емес.

## 4. Vercel-ге жариялау

1. Vercel-де өз аккаунтыңызға кіріп, workspace/team таңдаңыз.
2. **Add New → Project → Import Git Repository** арқылы
   `ramadanurk-commits/BotStore` репозиторийін таңдаңыз. Root Directory — түбір.
3. `vercel.json` build командасын береді: `npm run build:vercel`.
   Output Directory — `.next-vercel`. Node.js — 24.x.
4. Қорғалған Environment Variables ішіне
   **`BOTSTORE_BACKEND_SERVICE_TOKEN`** қосу қажет. Оның мәні — тек осы
   қолданыстағы Site-қа арналған сервиске қатынау токені. Бұл ChatGPT API кілті
   немесе банк құпиясы емес. Ол Sites басқару қосылымынан алынып, тікелей
   Vercel-дің серверлік айнымалысына беріледі. Құпия мәнді чатқа, GitHub-қа,
   браузер кодының ішіне немесе `NEXT_PUBLIC_*` айнымалысына жазбаңыз.
   Бастапқы build те бұл мән болмаса тоқтайды.
5. Production және қажет болса Preview ортасына баптап, **Deploy** басыңыз.
   Бос конфигурациямен «сәтті, бірақ істемейтін» бет жарияланбайды.
6. Сәтті deployment берген нақты `.vercel.app` сілтемесін README-ге қосыңыз.

Vercel интеграциясы команда көрсетпесе, оны аккаунтқа қайта қосып, тиісті
workspace қолжетімді екенін тексеру керек. Команда ID-сін ойдан жазбаңыз.
Аккаунт/команда мен сервер айнымалысы дайын болмайынша Vercel-де жарияланды деп
есептелмейді. Қазіргі жұмыс істеп тұрған Site сілтемесі сақталады.

Жергілікті Vercel build-ті тексеру:

```powershell
npx --yes pnpm@11.25.0 install --frozen-lockfile
npm run typecheck
npm run test:vercel
npm run build:vercel
```

Сервер айнымалысы қорғалған Vercel environment-та немесе еленбейтін жергілікті
`.env.local` файлында болуы керек. Токенді терминал командасына аргумент етіп
қоспаңыз. Жергілікті әдеттегі VS Code демонстрациясына бұл токен қажет емес:
`desktop-start.mjs` бөлек локалдық базаны қолданады.

## 5. Кіру және тексеру

Vercel нұсқасында email/құпиясөз арқылы кіру бар. Бұрынғы ChatGPT аккаунтына
байланған сатып алуларды сақтау үшін алдымен қазіргі Site-қа кіріп,
**Жеке кабинет → Email арқылы кіруді қосу** қадамын орындаңыз. Әкімші де осы
жолмен бұрынғы рұқсаттарын сақтайды. Email адресін жай тіркеу админ құқығын бермейді.
ChatGPT OAuth-ы Vercel доменіне қосылған деп көрсетілмейді.

Vercel gateway арқылы ZIP жүктеу — ең көбі **4 МБ**; қазіргі Cloudflare
нұсқасында — 15 МБ. Себебі Vercel Function кіріс payload шегі 4.5 МБ.
Үлкен файлға бөлек тікелей жүктеу жолы қажет. Файл алу серверден stream арқылы
беріледі. Сервис токені қолданушыға төлем не админ құқығын бермейді.

Жариялаған соң міндетті түрде тексеріңіз:

1. Каталогты екі браузерде ашып, үш тілді ауыстыру.
2. Email арқылы тіркелу, кіру, шығу және бір реттік recovery кодын сақтау.
3. Тегін құралға тапсырыс жасап, ZIP жүктеу.
4. Қарапайым аккаунттың админге кіре алмайтынын тексеру.
5. Өтінім жіберіп, админнен оны қайта оқу.

Тестілерде жеке уақытша D1/R2 қолданылады; олар нақты банк аударымын дәлелдемейді.
Ақылы сатылым шарттары толтырылып, әкімші қосқаннан кейін ғана ашылады.
