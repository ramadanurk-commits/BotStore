# BotStore: GitHub и VS Code

Репозиторий проекта: https://github.com/ramadanurk-commits/BotStore

## Запуск на Windows

1. Установите Git и Node.js версии 22.13 или новее. После установки закройте и заново откройте VS Code, чтобы команды появились в терминале.
2. В PowerShell выполните:

```powershell
git clone https://github.com/ramadanurk-commits/BotStore.git
cd BotStore
node scripts/desktop-start.mjs
```

Скрипт установит зависимости, создаст локальную базу и запустит приложение. Откройте адрес, который появится в терминале; по умолчанию это http://127.0.0.1:5173. Также можно открыть `BotStore.code-workspace` и запустить `START-BOTSTORE.cmd`.

Если PowerShell пишет, что `node` не найден, проверьте установку командой `node -v` в новом терминале. Официальная загрузка Node.js: https://nodejs.org/en/download/

Локальный вход — тестовый режим для разработки на localhost. Производственная авторизация, пользователи, оплаты и загруженные файлы работающего сайта не переносятся вместе с исходниками. Настройки окружения описаны в примерах и в [TEAM-START.md](TEAM-START.md).

## Работа команды

Владелец репозитория должен добавить двух участников с доступом на запись; участники должны принять приглашения. Каждый работает из своего аккаунта и своей ветки, затем открывает pull request.

```powershell
git switch -c feature/my-change
# Внесите и проверьте полезное изменение.
git add <изменённые-файлы>
git commit -m "Describe the implemented change"
git push -u origin feature/my-change
```

Задания для трёх участников и проверки: [TEAM-START.md](TEAM-START.md). Объяснение новой функции сравнения и подготовка к защите: [docs/team-defense.md](docs/team-defense.md).

Код подготовлен с помощью Codex. Коммиты импорта на GitHub не заменяют три содержательных личных коммита каждого участника. Каждый должен понимать свой код и уметь изменить его на защите.
